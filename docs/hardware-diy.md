# 自制硬件详细说明

本文档介绍 OpenWild Agent 智能巢穴装置中需要自制的机械结构部分，包括晴雨板、雨水收集器、雾化喷雾导流槽和应急饮水器。装置外形如项目侧视图所示。

## 整体外形与布局

整机由九大模块组成，固定在一块背板上（建议规格：60cm × 45cm × 1.5cm 木板或铝合金板）：

| 编号 | 名称 | 位置 | 说明 |
|------|------|------|------|
| 1 | 气象仪 | 背板左上角 | 监测温度、湿度、气压 |
| 2 | USB 摄像头 | 背板左中部 | USB 接口，拍摄巢穴内部，记录动物活动 |
| 3 | 太阳能板 | 背板顶部中央 | 12V/5W，带保护二极管 |
| 4 | 主控机构 | 背板中央偏右 | ESP32-S3 核心板，详见版本说明 |
| 5 | 藤编巢穴 | 背板中下方 | 直径约 25cm，藤编工艺，悬挂固定 |
| 6 | 雾化加湿器 | 巢穴右下方 | 雾化片 + 小风扇，USB 供电 |
| 7 | 应急饮水器 | 背板右下角 | 宠物饮水器改造，详见本文档 |
| 8 | 喷雾导流槽 | 雾化加湿器与巢穴之间 | 亚克力板自制，详见本文档 |
| 9 | 晴雨板 | 背板顶部外侧 | 亚克力板自制，详见本文档 |

> **背板安装建议**：先在背板上用铅笔画好每个组件的轮廓和螺丝孔位，用电钻预钻孔（木工钻或金属钻按材质选用），再依次固定各组件。太阳能板和气象仪应装在背板最高处，避免被其他组件遮挡。

## 一、晴雨板（必做）

晴雨板是本装置的核心外观件，同时承担两项功能：
- **遮阳**：防止太阳直射导致巢穴内部温度过高
- **雨水导流**：将雨水引导至雨水收集器，避免积水浸泡设备

### 材料清单

| 材料 | 规格 | 数量 | 备注 |
|------|------|------|------|
| 亚克力板 | 厚度 3mm，尺寸略大于巢穴（建议 30cm × 30cm） | 1 块 | 透明或磨砂，淘宝/拼多多有售 |
| 亚克力板（导流板） | 厚度 2mm，15cm × 5cm | 1 块 | 制作雨水倒流槽 |
| 热熔胶或结构胶 | 防水型 | 1 管 | |
| M3 螺丝 + 螺母 | 长度 10mm | 4 套 | 固定晴雨板到背板 |

### 制作步骤

**第一步：切割亚克力板**

用激光切割机或手工锯将 3mm 亚克力板切割成所需形状。推荐尺寸为略大于巢穴外径约 5cm（即直径约 30cm 的圆形或方形均可），四角钻 M3 螺丝孔（孔径 3.2mm，防止崩边）。

> **没有激光切割机？** 可以在淘宝搜索"亚克力板来图切割"，上传 CAD 图或直接告诉商家尺寸和形状，5 元左右即可切割一件。推荐选透明磨砂款，兼顾美观和遮阳效果。

**第二步：制作雨水倒流槽**

用 2mm 亚克力板切割一条宽 3cm、长与晴雨板宽度相同的导流板。将导流板用热熔胶粘在晴雨板底面（朝向背板的一面），位于晴雨板下沿正中位置，角度略微倾斜（倾角 15°～20°），使雨水沿导流板流向背板右下角的雨水收集器。

**第三步：固定晴雨板**

晴雨板通过四角支柱（可用塑料柱或铝柱，间距约 3cm）悬挂在背板上方，不与背板直接接触，留出通风空间。用 M3 螺丝穿过亚克力板四角孔，再穿过支柱，最后固定在背板上。

### 效果验证

模拟降雨：用喷壶从晴雨板上方浇水，观察雨水是否全部沿倒流槽流向收集器，晴雨板下方边缘无明显滴水为合格。

## 二、雨水收集器（选做，推荐野外使用）

配合晴雨板的倒流槽，将雨水收集到储水容器中，供雾化加湿器循环使用，实现野外无人值守供水。

### 材料清单

| 材料 | 规格 | 数量 | 备注 |
|------|------|------|------|
| 塑料瓶（饮料瓶） | 500ml ～ 1.5L | 1 个 | 收集雨水 |
| PVC 管或硅胶软管 | 内径 5mm | 约 30cm | 导流管 |
| 热熔胶 | 防水型 | 1 管 | |

### 制作步骤

1. 将塑料瓶瓶口切掉，形成敞口容器
2. 在瓶身侧面靠近底部位置用电烙铁烫一个小孔（直径约 6mm），插入硅胶软管，用热熔胶密封
3. 将瓶口朝下倒置挂在背板右下角（与饮水器相邻），瓶口下方放置应急饮水器
4. 将晴雨板倒流槽的出口用短管连接到塑料瓶内
5. 雨水经晴雨板 → 导流管 → 塑料瓶 → 瓶口滴落 → 应急饮水器

> **维护注意**：野外环境下每月检查一次，清理瓶内落叶和蚊虫虫卵。冬季结冰地区冬季前排空存水，防止冻裂。

## 三、雾化加湿器 + 喷雾导流槽

雾化加湿器通过超声波雾化片产生细小水雾，配合喷雾导流槽将雾气均匀送入巢穴，模拟自然露水环境，特别适合孵化期使用。

### 材料清单

| 材料 | 规格 | 数量 | 备注 |
|------|------|------|------|
| 超声波雾化片 | 5V/2.5MHz，雾化量可调 | 1 个 | 淘宝约 3 元 |
| 小型静音风扇 | 5V/0.2A，5015 规格 | 1 个 | 将雾气吹向导流槽 |
| 亚克力板 | 3mm，尺寸约 25cm × 8cm | 1 块 | 制作喷雾导流槽 |
| USB 供电线 | 1 米 | 1 根 | 供电（可接太阳能控制器 5V 输出） |
| 热熔胶 / 结构胶 | 防水型 | 1 管 | |
| 雾化器吸水棉芯 | 直径约 8mm | 1 根 | 约 15cm |

### 制作步骤

**雾化加湿器组装**

1. 将雾化片焊接供电线（红正黑负），注意防潮处理（用热熔胶包封焊点）
2. 将吸水棉芯穿过雾化片中心孔（棉芯另一端放入应急饮水器中吸水）
3. 用热熔胶将雾化片固定在外壳底部（小塑料盒或 3D 打印外壳）
4. 小风扇用热熔胶固定在雾化片上方，向导流槽方向吹风

**喷雾导流槽制作**

1. 用 3mm 亚克力板切割一块宽约 8cm、长约 25cm 的长条形槽体
2. 将长条板沿长度方向略微弯折（用热风枪加热亚克力板即可弯曲），形成半圆形凹槽通道
3. 在槽体两端各开一个 1cm 圆孔，作为雾气入口和出口
4. 用热熔胶将导流槽固定在背板上，入口对准雾化加湿器风扇出口，出口对准藤编巢穴开口
5. 喷雾导流槽建议与水平面呈 5°～10° 仰角安装，让雾气自然飘入巢穴

**供电接法**

```
太阳能板 + → 太阳能控制器（5V 输出） → USB 线 → 雾化加湿器
                                              ↓
太阳能板 - → 太阳能控制器 GND → ESP32-S3 主控（受主控 GPIO 控制通断）
```

ESP32-S3 通过一个 N 沟道 MOSFET（如 AO3400）控制雾化加湿器供电，主控发出高电平信号时 MOSFET 导通，雾化加湿器启动。详见软件 `humidifier.lua` 模块。

### 效果验证

上电后观察：雾化片应迅速产生白色水雾，风扇将雾气沿导流槽吹入巢穴内部。巢穴内部应能在 5 分钟内看到明显雾气弥漫。用手背在巢穴开口处感受，应有明显湿润凉感。

## 四、应急饮水器（选做，野外使用推荐）

应急饮水器为野生动物提供可靠水源。方案采用改造宠物饮水器，结构简单、成本低、维护方便。

### 材料清单

| 材料 | 规格 | 数量 | 备注 |
|------|------|------|------|
| 宠物饮水器 | 容量约 1.5L，带储水盆 | 1 个 | 淘宝/宠物店约 20 元 |
| 硅胶软管 | 内径 5mm | 约 20cm | 连接雾化器吸水棒 |
| 502 胶水 | 快干型 | 1 瓶 | 密封连接处 |
| 浮球阀（可选） | 小型养龟用浮球阀 | 1 个 | 自动补水，保持水位 |

### 制作步骤

1. **改造饮水盆**：在宠物饮水器储水盆侧面靠近底部位置，用电烙铁烫一个直径 6mm 的孔，插入硅胶软管，用 502 胶水密封，作为雾化器吸水棒的供水口
2. **放置位置**：将饮水器固定在背板右下角，高度与雾化加湿器平齐或略低，确保棉芯吸水顺畅
3. **棉芯连接**：将雾化器吸水棒（棉芯）一端放入饮水器储水盆底部，另一端插入雾化加湿器的雾化片孔中，棉芯靠毛细作用持续供水
4. **自动补水（可选）**：如果安装了雨水收集器，将收集瓶的出口软管也接入饮水器储水盆，实现雨水自动补水。浮球阀控制最高水位，防止溢水

### 维护周期

| 项目 | 周期 | 操作 |
|------|------|------|
| 清洗储水盆 | 每 2 周 | 倒掉剩水，用清水冲洗干净 |
| 更换棉芯 | 每 1 个月 | 剪去变色部分，换上新棉芯 |
| 检查密封 | 每月首次维护时 | 确认软管连接无脱落、无渗漏 |

## 五、藤编巢穴安装

藤编巢穴是动物的实际栖息场所，安装位置最为关键。

### 藤编巢穴选择

- **规格**：直径 22～28cm，深度 15～20cm，开口角度约 45°
- **材质**：天然藤编或柳条编织，透气性好
- **购买渠道**：淘宝搜索"藤编鸟窝"或"藤编巢穴"，价格约 15～30 元

### 固定方式

1. 在背板上用电钻钻两个间距约 8cm 的小孔（孔径略小于挂钩钢丝直径）
2. 将长约 15cm 的软钢丝（或鱼线）穿过巢穴挂环，两端穿过背板孔，在背板背面拧紧并用热熔胶加固
3. 调整巢穴角度，使开口朝向摄像头方向（约 30° 俯角），便于拍摄内部画面
4. 在巢穴底部铺一层干净椰棕丝或干草，增加舒适度并利于保温

### 摄像头对焦调整

安装完成后，给 ESP32-S3 主控上电，打开主控的屏幕或串口监视器，确认 USB 摄像头画面清晰覆盖巢穴内部。若画面模糊，松开摄像头固定螺丝，微微调整角度后重新固定。

## 六、太阳能供电系统

### 材料清单

| 材料 | 规格 | 数量 | 备注 |
|------|------|------|------|
| 太阳能电池板 | 12V/5W，带二极管 | 1 块 | |
| 太阳能控制器 | 12V/5A，小型 | 1 个 | 防过充过放 |
| 18650 锂电池 | 3.7V/3000mAh | 2 节 | 并联成 3.7V/6000mAh |
| DC-DC 升压模块 | 3.7V → 5V/2A | 1 个 | 给 ESP32-S3 和外设供电 |

### 接线图

```
太阳能板 (+) → 太阳能控制器 (+) → [电池组] → DC-DC 升压 → 5V USB 输出
太阳能板 (-) → 太阳能控制器 (-)              ↓
                                         太阳能控制器 LOAD (+) → ESP32-S3 供电
                                         太阳能控制器 LOAD (-) → GND
```

### 太阳能控制器设置

进入太阳能控制器设置菜单，配置以下参数：
- **电池类型**：锂电池（Li-ion）
- **过充保护电压**：4.2V
- **过放保护电压**：3.0V
- **光控开灯阈值**：根据实际需要设置（本项目不需要）

## 七、完整装配流程（推荐顺序）

按以下顺序装配，避免互相干扰：

1. **背板准备**：切割背板，钻好所有固定孔
2. **太阳能板**：固定在背板顶部中央
3. **太阳能控制器 + 电池 + DC-DC 模块**：固定在背板右上角（接线最方便的位置）
4. **主控机构（透明盒）**：固定在背板中央偏右
5. **气象仪**：固定在背板左上角
6. **藤编巢穴**：挂在背板中下方
7. **USB 摄像头**：固定在巢穴上方，对准巢穴开口（USB 线走线注意不要挡住巢穴入口）
8. **雾化加湿器**：固定在巢穴右下方
9. **喷雾导流槽**：固定在雾化加湿器与巢穴之间
10. **应急饮水器**：固定在背板右下角
11. **晴雨板**：固定在背板最上方，通过支柱悬挂
12. **所有接线**：按接线图连接，检查正负极
13. **软件部署**：连接电脑，通过 ESP-Claw 工具复制脚本和配置到设备
14. **功能测试**：逐项测试各模块是否正常工作
15. **背板封闭**：用透明防水薄膜或有机玻璃罩覆盖整个背板（可选，防止雨水溅入）
